# Cognova AI - Frontend

*Notes In. Knowledge Out.*

Frontend application for Cognova AI - an AI-powered study assistant.

## Features

- Google OAuth login
- Upload and organize study notes/PDFs
- AI-generated summaries
- AI-generated quizzes with instant scoring and feedback
- Chat with your documents using RAG (Retrieval-Augmented Generation)
- Analytics dashboard tracking quiz performance and weak topics

## Tech Stack

- React (Vite)
- Tailwind CSS
- React Router
- Axios
- Recharts

## Setup

1. Clone the repository

2. Install dependencies

        npm install

3. Start the development server

        npm run dev

4. The app expects the backend API to be running at http://127.0.0.1:8000
